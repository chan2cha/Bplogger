# Pulse Log 개인정보처리방침

시행일: 2026년 5월 11일

Pulse Log는 사용자가 직접 입력한 혈압과 체중 기록을 관리하기 위한 Android 앱입니다. 본 방침은 Pulse Log가 어떤 개인정보와 건강 관련 정보를 처리하는지 설명합니다.

## 1. 처리하는 정보

Pulse Log는 사용자가 앱에 직접 입력한 다음 정보를 기기 안에 저장합니다.

- 날짜별 아침 혈압
- 날짜별 저녁 혈압
- 날짜별 체중
- 각 기록의 측정 시각
- 알림 설정 값

Pulse Log는 이름, 전화번호, 이메일 주소, 위치 정보, 광고 식별자, 연락처, 사진, 마이크, 카메라 정보를 수집하지 않습니다.

## 2. 정보의 저장 위치

입력된 혈압과 체중 기록은 사용자의 기기 로컬 데이터베이스에 저장됩니다.

Pulse Log는 자체 서버를 운영하지 않으며, 사용자의 기록을 개발자 서버로 전송하지 않습니다.

## 3. 정보의 이용 목적

저장된 정보는 다음 목적에만 사용됩니다.

- 날짜별 혈압과 체중 기록 표시
- 캘린더 기록 상태 표시
- 최근 혈압과 체중 추이 그래프 표시
- CSV 파일 또는 PDF 요약본 생성
- 앱 내 알림 설정 저장

## 4. 제3자 제공 및 공유

Pulse Log는 사용자의 기록을 자동으로 제3자에게 제공하지 않습니다.

다만 사용자가 앱의 내보내기 기능을 직접 실행하면, CSV 파일 또는 PDF 요약본이 생성되고 Android 공유 시트를 통해 사용자가 선택한 외부 앱으로 전달될 수 있습니다. 예를 들어 이메일, 메신저, 클라우드 드라이브 앱으로 공유할 수 있습니다.

이 경우 공유 대상 앱에서의 정보 처리에는 해당 외부 앱의 개인정보처리방침이 적용됩니다.

## 5. 보관 및 삭제

Pulse Log의 기록은 사용자의 기기에 보관됩니다.

사용자는 앱 안에서 개별 기록을 삭제할 수 있습니다. 앱을 삭제하면 기기에 저장된 Pulse Log의 로컬 데이터도 함께 삭제될 수 있습니다. 단, 사용자가 이미 외부 앱으로 공유한 CSV 파일 또는 PDF 파일은 해당 외부 앱이나 저장 위치에서 별도로 삭제해야 합니다.

## 6. 인터넷 및 서버 전송

Pulse Log의 핵심 기록 기능은 인터넷 연결 없이 사용할 수 있습니다.

현재 앱은 사용자의 혈압, 체중, 알림 설정 데이터를 개발자 서버로 전송하지 않습니다.

## 7. 아동의 개인정보

Pulse Log는 아동을 대상으로 하지 않습니다. 보호자의 동의 없이 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 8. 보안

Pulse Log는 사용자의 기록을 기기 로컬 저장소에 보관합니다. 사용자는 기기 잠금, 백업 설정, 공유 대상 앱 선택을 직접 관리해야 합니다. 건강 관련 기록은 민감할 수 있으므로 CSV 또는 PDF 파일 공유 시 전달 대상 앱과 수신자를 신중히 선택해 주세요.

## 9. 방침 변경

앱 기능 변경이나 법령 변경에 따라 본 개인정보처리방침이 수정될 수 있습니다. 변경 시 본 문서의 시행일을 갱신합니다.

## 10. 문의

개인정보처리방침 관련 문의는 앱 배포자가 Play Console에 등록한 개발자 연락처로 문의해 주세요.
