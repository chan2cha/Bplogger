# Pulse Log 정책 결정 기록

## 1. 이미 확정된 내용

- 캘린더는 앱 내부 캘린더로 구현한다.
- OS 캘린더 직접 연동은 현재 범위에 포함하지 않는다.
- 아침과 저녁 혈압은 따로 저장한다.
- 체중은 선택 입력이다.
- 메모는 날짜 단위로 저장한다.
- 메모는 과거/오늘/미래 날짜 모두 편집 가능하다.
- 측정 시간은 저장 시점의 기기 시각으로 자동 저장한다.
- 수정 시 측정 시간은 유지한다.
- 앱 첫 진입 시 오늘 날짜를 기본 선택한다.
- 메인 화면은 선택 날짜 기준의 빠른 입력이 중심이다.
- 날짜 탭의 1차 동작은 상세 진입이 아니라 입력 대상 날짜 변경이다.
- 상세 화면은 세부 수정과 관리용 보조 화면이다.
- 그래프 기간은 최근 7일 / 최근 30일 최근 기준이다.

## 2. 정책 결정 기록

### 2.1 저장 구조

답변:

```text
1세트의 개념은 없다. 아침과 저녁은 따로 저장이며, 월별 캘린더에는 아침/저녁 모두 없는 경우, 아침만 있는 경우, 저녁만 있는 경우, 모두 있는 경우 총 4가지 상태로 관리하여 표시한다.
```

### 2.2 날짜별 입력 허용 범위

답변:

```text
혈압 및 체중은 선택한 날짜에 기존 기록이 없으면 신규 추가 가능하고, 기존 기록이 있으면 조회/수정이 가능하다. 메모는 과거/미래/오늘을 구분하지 않고 추가, 수정, 삭제가 가능하다.
```

### 2.3 입력값 검증 범위

답변:

```text
혈압은 50~200, 체중은 0~100kg, 소수점은 둘째 자리까지 반올림으로 하며 비정상 수치 입력 시 저장 차단 정책을 사용한다.
```

### 2.4 알림 정책

답변:

```text
알림 시각과 재알림 여부 및 횟수는 사용자가 앱 내에서 설정 및 관리할 수 있어야 한다.
```

### 2.5 그래프 정책

답변:

```text
기본 기간은 최근 7일이고 탭으로 최근 7일/최근 30일을 볼 수 있도록 한다. 혈압은 수축기/이완기 2라인으로 하며 체중 그래프는 따로 하되 같은 화면에서 동시에 보이게 한다.
```

### 2.6 메인/상세 역할 정책

답변:

```text
앱 첫 진입 시에는 오늘 날짜를 기본 선택한다. 메인 화면은 선택 날짜 기준의 빠른 입력이 중심이며, 상세 화면은 세부 수정과 관리용 보조 화면으로 사용한다. 날짜 탭의 1차 동작은 상세 진입이 아니라 입력 대상 날짜 변경이다.
```

### 2.7 메모 표시 정책

답변:

```text
메모를 입력한 날짜는 달력에 별표를 추가하는 느낌으로 표시하고, 선택 날짜 요약 영역에서는 날짜 아래에 메모를 간략하게 보여준다.
```

### 2.8 디자인 방향 정책

답변:

```text
전체적인 톤은 혈압 앱에 맞는 산뜻한 핑크와 적색 계열로 통일한다. 캘린더, 빠른 입력, 그래프, 설정 화면은 같은 디자인 언어를 유지한다.
```

## 3. 현재 남아 있는 결정 포인트

- 실제 OS 알림 스케줄링 구현 방식 선정
- 런처 앱명과 아이콘 최종 브랜딩 확정
- 상세 화면 입력 스타일을 어디까지 메인과 통일할지 최종 결정
