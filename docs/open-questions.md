# Pulse Log 정책 결정 기록

## 1. 이미 확정된 내용

- 캘린더는 앱 내부 캘린더로 구현한다.
- OS 캘린더 직접 연동은 현재 범위에 포함하지 않는다.
- 아침과 저녁 혈압은 따로 저장한다.
- 체중은 선택 입력이다.
- 측정 시간은 저장 시점의 기기 시각으로 자동 저장한다.
- 수정 시 측정 시간은 유지한다.
- 앱 첫 진입 시 오늘 날짜를 기본 선택한다.
- 입력 탭은 선택 날짜 기준의 빠른 입력이 중심이다.
- 설정은 헤더 우측 톱니바퀴로 진입한다.
- 날짜 탭의 1차 동작은 입력 대상 날짜 변경이다.
- 별도 상세 화면은 현재 사용자 흐름에서 제외한다.
- 날짜 메모는 현재 UI에서 사용하지 않는다.
- 그래프 기간은 최근 7일 / 최근 30일 최근 기준이다.
- 혈압 그래프는 수축기/이완기 2라인으로 유지한다.
- 아침/저녁 분리 그래프는 현재 범위에서 제외한다.
- 그래프에서 선택한 날짜는 캘린더 탭으로 연결한다.
- 캘린더 선택 날짜 요약은 월력 카드 상단에 통합한다.
- 입력된 아침 혈압, 저녁 혈압, 체중은 항목별 삭제 가능하며 삭제 전 확인한다.
- 그래프에서 미기록 날짜를 건너는 연결 구간은 점선으로 표시한다.
- 기록 데이터는 최근 30일 또는 전체 범위로 CSV 또는 PDF 요약본 공유할 수 있다.

## 2. 정책 결정 기록

### 2.1 저장 구조

답변:

```text
1세트의 개념은 없다. 아침과 저녁은 따로 저장이며, 월별 캘린더에는 아침/저녁 모두 없는 경우, 아침만 있는 경우, 저녁만 있는 경우, 모두 있는 경우 총 4가지 상태로 관리하여 표시한다.
```

### 2.2 날짜별 입력 허용 범위

현재 정책:

```text
혈압 및 체중은 선택한 날짜에 기존 기록이 없으면 신규 추가 가능하고, 기존 기록이 있으면 조회/수정/삭제 가능하다. 입력, 수정, 삭제는 입력 탭의 빠른 입력 카드에서 수행한다. 캘린더 탭은 선택 날짜를 바꾸고 월력 카드 상단에서 선택 날짜 요약을 확인하는 흐름을 담당한다.
```

### 2.3 입력값 검증 범위

답변:

```text
혈압은 50~200, 체중은 0~100kg, 소수점은 둘째 자리까지 반올림으로 하며 비정상 수치 입력 시 저장 차단 정책을 사용한다.
```

### 2.4 알림 정책

답변:

```text
알림 시각과 재알림 여부 및 횟수는 사용자가 앱 내에서 설정 및 관리할 수 있어야 한다.
```

현재 상태:

```text
설정 저장 UI와 로컬 저장은 구현되어 있으나 실제 OS 알림 스케줄링은 아직 구현하지 않았다.
```

### 2.5 그래프 정책

현재 정책:

```text
기본 기간은 최근 7일이고 탭으로 최근 7일/최근 30일을 볼 수 있도록 한다. 혈압은 수축기/이완기 2라인으로 하며 체중 그래프는 따로 하되 같은 화면에서 동시에 보이게 한다.
```

추가 결정:

```text
그래프에는 x축/y축 값, 범례, 포인트, 선택 날짜 카드, 혈압 기준선을 표시한다. 선택한 날짜는 상세 화면이 아니라 캘린더 탭의 선택 날짜로 연결한다.
```

추가 결정:

```text
중간에 기록하지 않은 날짜가 있어도 앞뒤 실측값의 추이는 읽을 수 있게 하되, 실제 연속 측정으로 오해하지 않도록 미기록 날짜를 건너는 연결 구간은 연한 점선으로 표시한다.
```

### 2.6 상세/메모 정책

현재 정책:

```text
별도 상세 화면과 날짜 메모는 현재 사용자 흐름에서 제외한다. 기존 상세 화면 파일, DailyNote 테이블, note 관련 Repository/ViewModel API는 마이그레이션 리스크 때문에 일단 보존한다.
```

### 2.7 디자인 방향 정책

답변:

```text
전체적인 톤은 혈압 앱에 맞는 산뜻한 핑크와 적색 계열로 통일한다. 캘린더, 빠른 입력, 그래프, 설정 화면은 같은 디자인 언어를 유지한다.
```

추가 결정:

```text
기본 Material 회색 터치 피드백이 화면 톤과 어긋나는 부분은 앱 포인트 컬러 기반 ripple 또는 softClickable로 통일한다.
```

### 2.8 내보내기 정책

현재 정책:

```text
내보내기는 헤더 우측 공유 아이콘에서 독립 화면으로 제공한다. 최근 30일 또는 전체 기록을 UTF-8 BOM 포함 CSV와 PDF 요약본으로 생성하고 Android 공유 시트를 통해 이메일, 메신저, 드라이브 앱으로 전달한다. PDF 요약본은 기록 기간, 기록 건수, 평균값, 최근 추이 그래프, 최근 기록 표를 포함한다.
```

## 3. 현재 남아 있는 결정 포인트

- 실제 OS 알림 스케줄링 구현 방식 선정
- 런처 앱명과 아이콘은 `Pulse Log`와 하트 로고 기반으로 정리됨
- `daily_notes` 테이블과 미사용 상세 화면 코드를 언제 제거할지 결정
