# Pulse Log 현재 문제점 정리

## 1. 현재 해결된 주요 문제

- 메인 입력이 상세 화면에 묻혀 있던 구조를 정리했다.
- 캘린더를 버튼 나열형에서 컴팩트 월력형으로 바꿨다.
- 메인 입력, 그래프, 설정의 톤을 대체로 통일했다.
- 화면 코드를 기능별 파일로 분리했다.
- 저장/수정 피드백을 배너에서 스낵바로 바꿨다.
- 키보드 바깥 터치 닫힘과 저장 후 키보드 닫힘을 반영했다.
- 세그먼트 탭 인디케이터의 음수 패딩 크래시를 수정했다.

## 2. 현재 남아 있는 문제

### 2.1 알림 기능 미완성

- 설정 저장 UI는 있지만 실제 OS 알림 스케줄링은 아직 없다.
- 현재는 알림 설정 화면이 데이터 입력 화면에 가깝다.

### 2.2 DB 마이그레이션 리스크

- `fallbackToDestructiveMigration()` 사용 중이다.
- 스키마 변경 시 기존 데이터가 삭제될 수 있다.

### 2.3 상세 화면 톤 불균형

- 상세 화면은 메인 빠른 입력 대비 컴포넌트 일관성이 아직 약하다.
- 입력 필드와 액션 버튼 구조를 한 번 더 정리할 여지가 있다.

### 2.4 설정 입력 검증 부족

- 시간 입력이 자유 텍스트라 `HH:mm` 형식 오류가 발생할 수 있다.
- 재알림 횟수의 상한/하한 정책이 약하다.

### 2.5 그래프 확장성 부족

- 현재 그래프는 Canvas 기반 단순 라인 차트다.
- 축 눈금, 범례, 포인트 강조, 제스처 확대 같은 기능이 없다.

### 2.6 브랜딩 정리 미완료

- 앱 내부 헤더 표기는 `Pulse Log`로 바뀌었지만 런처 앱명과 아이콘은 별도 정리가 필요하다.

## 3. 운영상 리스크

- 화면 회전과 프로세스 재생성 시 상태 복원 검증이 충분하지 않다.
- 실제 기기별 키보드 동작 차이를 더 확인해야 한다.
- Compose 애니메이션 변경 시 레이아웃 깨짐이 다시 생길 수 있다.

## 4. 현재 우선순위

### 높은 우선순위

- 실제 알림 스케줄링 구현
- Room 마이그레이션 전략 수립
- 상세 화면 컴포넌트 통일
- 설정 입력 검증 강화

### 중간 우선순위

- 그래프 고도화
- 런처 이름과 앱 아이콘 정리
- 테스트 코드 추가
