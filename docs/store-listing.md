## 자세한 설명

```text
Pulse Log는 혈압과 체중을 날짜별로 간편하게 기록하고 확인할 수 있는 건강 기록 앱입니다.

아침 혈압, 저녁 혈압, 체중을 선택한 날짜에 저장하고, 캘린더에서 기록 상태를 한눈에 확인할 수 있습니다. 최근 7일 또는 30일 기준 그래프로 수축기, 이완기, 체중 추이를 확인할 수 있으며, 기록이 없는 날짜는 구분되어 표시됩니다.

병원 방문이나 상담을 위해 최근 30일 또는 전체 기록을 CSV 파일이나 PDF 요약본으로 내보낼 수 있습니다. PDF 요약본에는 기록 기간, 평균 혈압, 평균 체중, 최근 추이 그래프, 최근 기록 표가 포함됩니다.

주요 기능:
- 날짜별 아침 혈압, 저녁 혈압, 체중 기록
- 캘린더 기반 기록 상태 확인
- 최근 7일 / 30일 혈압 및 체중 그래프
- 수축기, 이완기, 체중을 구분한 추이 표시
- CSV 원본 데이터 내보내기
- 병원 제출용 PDF 요약본 내보내기
- 기기 로컬 저장 기반 기록 관리

Pulse Log는 사용자의 건강 기록을 개발자 서버로 전송하지 않습니다. 입력한 기록은 기기 안에 저장되며, 사용자가 직접 내보내기를 선택한 경우에만 CSV 또는 PDF 파일로 외부 앱에 공유됩니다.

본 앱은 혈압과 체중 기록을 돕는 보조 도구이며, 의학적 진단이나 치료를 제공하지 않습니다. 건강 상태와 치료에 관한 판단은 의료 전문가와 상담하세요.
```

## Data Safety 응답 기준

- 개발자 서버로 사용자 데이터를 수집하지 않음
- 혈압/체중 기록은 기기 로컬 Room DB에 저장
- 사용자가 직접 내보내기를 선택한 경우에만 CSV/PDF 파일이 Android 공유 시트를 통해 외부 앱으로 전달됨
- 광고 SDK와 광고 ID 사용 없음
