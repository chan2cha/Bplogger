# Pulse Log 작업 소통 문서

## 1. 목적

이 문서는 현재 프로젝트에 대해 느끼는 문제점, 개선 요청, 방향 변경 사항을 정리해서 AI와 지속적으로 소통하기 위한 창구다.

## 2. 사용 방식

아래 항목 중 필요한 것만 적으면 된다.

- 마음에 안 드는 점
- 왜 마음에 안 드는지
- 원하는 방향
- 원하지 않는 방향
- 급한 순서
- 이번 턴에서 바로 수정했으면 하는 범위

## 3. 내가 이 문서를 읽을 때의 기준

1. 현재 무엇이 문제인지
2. 그 문제가 디자인 문제인지, 기능 문제인지, 구조 문제인지
3. 반드시 지켜야 하는 요구인지, 선호 수준인지
4. 지금 바로 수정해야 하는지, 나중에 정리해도 되는지

## 5. 현재 합의된 방향

- 앱 첫 진입 시 오늘 날짜를 기본 선택한다.
- 입력 탭은 선택 날짜 기준으로 동작한다.
- 입력 탭은 빠른 입력이 우선이다.
- 설정은 헤더 우측 톱니바퀴로 진입한다.
- 캘린더는 확인 중심의 컴팩트한 UI를 지향한다.
- 캘린더 선택 날짜 요약은 월력 카드 상단에서 바로 바뀐다.
- 날짜 탭의 기본 동작은 입력 대상 날짜 변경이다.
- 별도 상세 화면은 현재 사용자 흐름에서 제외한다.
- 날짜 메모는 현재 UI에서 사용하지 않는다.
- 그래프는 추이 확인과 캘린더 이동의 연결점이다.
- 그래프에서 선택한 날짜는 캘린더 탭에서 선택된 상태로 보여준다.
- 그래프 미기록 날짜를 건너는 연결 구간은 점선으로 표시한다.
- 입력 탭의 삭제 동작은 확인 다이얼로그를 거친다.
- 입력 탭의 저장/삭제 버튼은 입력란과 같은 행에서 조작한다.
- 헤더 우측 공유 아이콘에서 최근 30일 또는 전체 기록 CSV/PDF 요약본을 공유한다.
- 전체 톤은 밝은 핑크/적색 계열을 중심으로 하되 그래프 라인은 명확히 구분한다.

## 6. 현재 코드 기준 보완 요청 후보

### 후보 A. 알림 실제 동작

- 분류: 기능 / UX
- 예시 문제: 설정 저장은 되는데 실제 알림은 오지 않는다.

### 후보 B. 데이터 보존

- 분류: 데이터
- 예시 문제: DB migration 없이 destructive migration 상태라 업데이트 시 기록이 사라질 수 있다.

### 후보 C. 설정 시간 입력 UX

- 분류: UX / 기능
- 예시 문제: `HH:mm` 자유 입력은 오타가 나기 쉽다.

### 후보 D. 미사용 코드 최종 정리

- 분류: 구조 / 데이터
- 예시 문제: 상세 화면과 메모 관련 코드가 남아 있지만 현재 UI에서는 사용하지 않는다.

### 후보 E. 그래프/캘린더 UI 테스트

- 분류: 테스트
- 예시 문제: 그래프 선택 날짜가 캘린더 선택 날짜로 이어지는 흐름을 자동 검증하지 않는다.

### 후보 F. 빌드 도구 경고 정리

- 분류: 구조 / 빌드
- 예시 문제: KSP 생성 소스 호환을 위해 `android.disallowKotlinSourceSets=false` experimental 설정이 남아 있다.

### 후보 G. 병원 제출용 리포트

- 분류: 기능 / 문서
- 예시 문제: PDF 요약본에는 최근 추이 그래프가 포함되어 있으나 병원별 제출 양식은 아직 없다.
