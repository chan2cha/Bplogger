# Pulse Log 작업 소통 문서

## 1. 목적

이 문서는 현재 프로젝트에 대해 느끼는 문제점, 불만, 개선 요청, 방향 변경 사항을 문서로 정리해서 AI와 지속적으로 소통하기 위한 창구다.

## 2. 사용 방식

이 문서에는 아래 중 필요한 것만 적으면 된다.

- 마음에 안 드는 점
- 왜 마음에 안 드는지
- 원하는 방향
- 절대 원하지 않는 방향
- 급한 순서
- 이번 턴에서 바로 수정했으면 하는 범위

## 3. 내가 이 문서를 읽을 때의 기준

1. 현재 무엇이 문제인지
2. 그 문제가 디자인 문제인지, 기능 문제인지, 구조 문제인지
3. 반드시 지켜야 하는 요구인지, 선호 수준인지
4. 지금 바로 수정해야 하는지, 나중에 정리해도 되는지

## 6. 우선순위 기준

- `P0`: 지금 방향이 잘못돼서 바로 멈추고 수정해야 하는 것
- `P1`: 다음 작업에서 우선 반영해야 하는 것
- `P2`: 개선하면 좋지만 당장 막히지는 않는 것
- `P3`: 아이디어나 장기 개선 항목

## 7. 분류 기준

- `UI`: 색상, 배치, 컴포넌트 모양, 화면 밀도
- `UX`: 흐름, 버튼 위치, 입력 방식, 피드백 방식
- `기능`: 동작 자체가 잘못됐거나 부족한 경우
- `구조`: 코드 구조, 화면 구조, 상태 관리, 설계 방향
- `성능`: 느림, 버벅임, 불필요한 재렌더링, 로딩 문제
- `데이터`: DB 구조, 저장 정책, 검증, 마이그레이션
- `문서`: README, docs, 정책 문서, 설명 부족

## 8. 현재 합의된 방향

- 앱 첫 진입 시 오늘 날짜를 기본 선택한다.
- 메인 화면 입력은 선택 날짜 기준으로 동작한다.
- 메인 화면은 빠른 입력이 우선이다.
- 캘린더는 확인 중심의 컴팩트한 UI를 지향한다.
- 날짜 탭의 기본 동작은 상세 진입이 아니라 입력 대상 날짜 변경이다.
- 상세 화면은 세부 수정과 관리용 보조 화면이다.
- 메모가 있는 날짜는 달력에 별표로 표시한다.
- 선택 날짜 요약 영역에는 메모 미리보기를 노출한다.
- 전체 톤은 밝은 핑크/적색 계열로 통일한다.

## 9. 현재 코드 기준 보완 요청 후보

아래 항목들은 지금 문서에 추가하면 바로 다음 작업 우선순위로 삼기 좋다.

### 후보 A. 알림 실제 동작

- 분류: 기능 / UX
- 예시 문제: 설정 저장은 되는데 실제 알림은 오지 않는다.

### 후보 B. 상세 화면 톤 통일

- 분류: UI / 구조
- 예시 문제: 메인 입력과 상세 화면 디자인 언어가 아직 다르다.

### 후보 C. 앱명 / 아이콘 정리

- 분류: UI / 문서
- 예시 문제: 내부 헤더는 Pulse Log인데 런처명과 아이콘은 아직 정리되지 않았다.

### 후보 D. 시간 입력 UX

- 분류: UX / 기능
- 예시 문제: `HH:mm` 자유 입력은 오타가 나기 쉽다.

### 후보 E. 데이터 보존

- 분류: 데이터
- 예시 문제: DB migration 없이 destructive migration 상태라 업데이트 시 기록이 사라질 수 있다.
