# Pulse Log 개발 TODO

## 1. 목적

현재 구현 상태를 기준으로 남은 작업과 보완 포인트를 다시 분해한 체크리스트다.

## 2. P0 - 안정화

- 실제 기기에서 저장/수정/삭제 주요 흐름 재검증
- 세그먼트 탭 전환과 레이아웃 깨짐 재검증
- 화면 회전과 프로세스 재생성 상태 확인
- 키보드 동작 기기별 점검

완료 조건:

- 캘린더, 그래프, 설정 탭 전환 시 크래시 없음
- 저장 버튼 누름 후 키보드가 정상적으로 내려감
- 키보드 표시 중 레이아웃이 과도하게 깨지지 않음

## 3. P1 - 알림 기능 완성

- 알림 시간 형식 검증 추가
- 재알림 횟수 검증 추가
- 아침/저녁 미기록 판정 로직 정리
- `AlarmManager` 또는 `WorkManager` 기반 실제 스케줄링 구현
- 날짜 변경 시 알림 상태 재계산

완료 조건:

- 설정 저장뿐 아니라 실제 알림이 동작함
- 잘못된 시간 입력은 저장 차단 또는 수정 유도

## 4. P1 - 데이터 안정성

- Room 마이그레이션 전략 수립
- destructive migration 제거
- 기존 사용자 데이터 유지 시나리오 테스트

완료 조건:

- 스키마 변경 후에도 기존 데이터 유지 가능

## 5. P1 - 상세 화면 정리

- 상세 화면 입력 카드 재디자인
- 빠른 입력과 동일한 공용 입력 컴포넌트 적용
- 삭제 버튼과 메모 입력 UX 정리

완료 조건:

- 메인 / 상세 화면 디자인 언어 통일
- 상세 화면도 유지보수하기 쉬운 공용 컴포넌트 구조 사용
