# Pulse Log 개발 TODO

## 1. 목적

현재 구현 상태를 기준으로 남은 작업과 보완 포인트를 정리한다.

## 2. P0 - 안정화

- 실제 기기에서 저장/수정 주요 흐름 재검증
- 입력, 캘린더, 그래프 탭 전환 재검증
- 헤더 톱니바퀴 설정 진입/복귀 흐름 검증
- 그래프 날짜 선택 후 캘린더 이동 흐름 검증
- 캘린더 월력 카드 상단 선택 날짜 요약과 입력 탭 이동 버튼 검증
- 입력 탭 삭제 확인 다이얼로그와 삭제 후 반영 검증
- 화면 회전과 프로세스 재생성 상태 확인
- 키보드 동작 기기별 점검

완료 조건:

- 입력, 캘린더, 그래프 탭 전환 및 설정 진입 시 크래시 없음
- 저장 버튼 누름 후 키보드가 정상적으로 내려감
- 입력란과 저장/삭제 버튼이 같은 행에서 정렬되어 보임
- 삭제 확인 후 입력 필드, 캘린더 상태, 그래프가 즉시 갱신됨
- CSV/PDF 공유 버튼이 Android 공유 시트를 열고 파일을 전달함
- 그래프에서 선택한 날짜가 캘린더 탭에 정확히 반영됨
- 키보드 표시 중 레이아웃이 과도하게 깨지지 않음
