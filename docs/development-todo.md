# Bplogger 개발 TODO

## 1. 목표

확정된 정책 기준으로 Android 구현 작업을 다시 분해한 체크리스트다.
현재 우선순위는 메인 입력 우선 UX와 컴팩트한 캘린더 재구성이다.

## 2. P0 - 구현 전 최종 정리

- 첫 진입 시 오늘 날짜 자동 선택 정책 반영
- 캘린더 4상태 색상값과 접근성 라벨 문구 확정
- 혈압/체중/메모 삭제 UX 문구 확정
- 알림 설정 기본값 확정

## 3. P1 - 데이터 계층 재구성

- 기존 `BpRecord` 기반 구조 교체 또는 마이그레이션 전략 수립
- `DailyHealthRecord` 엔티티 추가
- `DailyNote` 엔티티 추가
- `NotificationSettings` 저장 모델 추가
- 월력 상태 조회 모델 정의
- Room DAO 재설계
- Repository 재설계

완료 조건:

- 날짜별 혈압/체중 조회 가능
- 기록 없는 날짜 신규 저장 가능
- 기록 있는 날짜 수정 가능
- 메모 저장/조회/삭제 가능
- 알림 설정 저장 가능

## 4. P1 - 화면 구조 전환

- 메인 탭 구조 정리
- 메인 입력 우선 레이아웃 반영
- 월별 캘린더 화면 재구성
- 일별 상세 화면 역할 축소
- 그래프 화면 유지
- 알림 설정 화면 유지

완료 조건:

- 앱 진입 시 캘린더 탭 표시
- 앱 진입 시 오늘 날짜 기본 선택
- 날짜 클릭 시 메인 입력 대상 날짜 변경
- 설정 화면 진입 가능

## 5. P1 - 캘린더 및 입력

- 월력 헤더 구현
- 컴팩트 월력 그리드 구현
- 이전/다음 월 이동 구현
- 날짜 선택 상태 구현
- 4상태 마커 렌더링 구현
- 빠른 입력 카드 구현
