# Pulse Log 기획 정리

## 1. 기획 요약

Pulse Log는 날짜 단위 혈압/체중 기록 앱이다.
현재 제품 중심은 `빠른 입력`, `캘린더 확인`, `그래프에서 추이 파악`이다.

## 2. 현재 핵심 가치

- 빠른 저장: 앱 첫 진입 시 입력 탭에서 오늘 날짜 기록 입력
- 빠른 복구: 잘못 입력한 항목은 확인 다이얼로그를 거쳐 항목별 삭제
- 빠른 전환: 날짜를 바꾸면 즉시 해당 날짜 입력 대상으로 전환
- 빠른 확인: 월별 캘린더로 아침/저녁 기록 상태 확인
- 추이 확인: 최근 7일/30일 그래프에서 혈압과 체중 변화 확인
- 연결 흐름: 그래프에서 선택한 날짜를 캘린더 탭에서 바로 수정

## 3. 현재 사용자 시나리오

### 시나리오 A. 오늘 기록 저장

1. 사용자가 앱을 실행한다.
2. 앱은 오늘 날짜를 기본 선택한 상태로 입력 탭을 보여준다.
3. 사용자는 빠른 입력 카드에서 아침 혈압, 저녁 혈압, 체중을 입력한다.
4. 저장 직후 스낵바 피드백이 뜨고 캘린더 상태가 즉시 갱신된다.

### 시나리오 B. 다른 날짜 기록 수정

1. 사용자가 캘린더에서 날짜를 선택한다.
2. 메인 입력 대상 날짜가 즉시 바뀐다.
3. 월력 카드 상단 요약이 해당 날짜 데이터로 즉시 바뀐다.
4. 사용자는 `이 날짜 입력하기`를 눌러 입력 탭에서 수정한다.

### 시나리오 C. 그래프에서 날짜 확인 후 수정

1. 사용자가 그래프 탭에서 최근 7일 또는 30일 추이를 확인한다.
2. 그래프를 탭해 날짜 열을 선택한다.
3. 선택 카드에서 해당 날짜 값과 기준선 대비 상태를 확인한다.
4. `캘린더에서 보기`를 눌러 캘린더 탭으로 이동한다.
5. 캘린더 월력 카드 상단에서 해당 날짜 요약을 확인한 뒤 입력 탭으로 이동해 수정한다.

## 4. 현재 화면 구조

- 상단 헤더와 내보내기/설정 아이콘
- 세그먼트 탭
  - 입력
  - 캘린더
  - 그래프

별도 상세 화면과 날짜 메모는 현재 사용자 흐름에서 제외한다.

## 5. 탭별 기획 포인트

### 5.1 입력 탭

- 선택 날짜 기준 빠른 입력을 제공한다.
- 아침 혈압, 저녁 혈압, 체중을 한 화면에서 저장/수정/삭제한다.
- 입력란과 저장/삭제 아이콘 버튼은 같은 행에 배치해 조작 대상을 직관적으로 연결한다.
- 삭제는 확인 다이얼로그에서 확정한 뒤 실행한다.
- 선택 날짜는 캘린더/그래프와 공유한다.

### 5.2 캘린더 탭

- 월력 카드가 상단에 위치한다.
- 날짜별 아침/저녁 기록 상태를 표시한다.
- 날짜 선택은 상세 진입이 아니라 입력 대상 변경이다.
- 월력 카드 상단에 선택 날짜 기록 요약을 표시한다.
- 선택 날짜 요약에서 입력 탭으로 이동할 수 있다.

### 5.3 그래프 탭

- 최근 7일 / 최근 30일 전환 제공
- 혈압과 체중을 같은 화면에서 확인
- x축/y축, 범례, 포인트, 기준선을 제공
- 미기록 날짜를 건너는 연결은 점선으로 표시
- 날짜 열 선택 후 값 카드를 표시
- 선택 날짜를 캘린더 탭으로 연결

### 5.4 설정 화면

- 알림 시간과 재알림 정책 저장
- 헤더 우측 톱니바퀴에서 진입
- 빠른 입력 카드와 같은 시각 톤 유지
- 디버그 빌드에서 그래프 테스트 데이터 생성 액션 제공

### 5.5 내보내기 화면

- 헤더 우측 공유 아이콘에서 진입
- 최근 30일 / 전체 기록 CSV 공유
- 최근 30일 / 전체 기록 PDF 요약본 공유
- Android 공유 시트로 이메일, 메신저, 드라이브 앱에 전달

## 6. 현재 구현 완료 범위

- 입력 탭 중심 빠른 입력 구조
- 컴팩트 월력 UI
- 월력 카드 상단 선택 날짜 요약 통합
- 스낵바 피드백
- 바깥 영역 터치 시 키보드 내림
- 삭제 확인 다이얼로그
- 입력 화면과 설정 화면 톤 통일
- 최근 7일/30일 그래프
- 그래프 축/범례/포인트/선택 카드/기준선/미기록 점선 연결
- 그래프에서 캘린더 선택 날짜로 이동
- 헤더 공유 아이콘 기반 CSV/PDF 데이터 내보내기
- 하네스 설계 문서와 로컬 체크 스크립트

## 7. 다음 기획 우선순위

### Phase 1. 안정화

- 실제 기기에서 캘린더/그래프/설정 탭 전환 검증
- 그래프 선택 카드와 캘린더 이동 흐름 검증
- 화면 회전과 프로세스 재생성 상태 확인

### Phase 2. 기능 완성

- 실제 알림 스케줄링
- 병원별 제출 양식 고도화
- DB 마이그레이션 전략

### Phase 3. 품질 강화

- ViewModel 테스트
- Compose UI 테스트
- 접근성 개선
- 사용하지 않는 상세/메모 코드 최종 정리

## 8. 기획상 주의점

- 입력이 확인보다 늦게 인지되면 안 된다.
- 입력 탭은 기록 저장 도구, 캘린더는 상태 확인과 입력 대상 선택 및 선택 날짜 요약 도구다.
- 그래프는 추이 확인과 캘린더 이동의 연결점이다.
- 별도 상세 화면이 다시 주 입력 흐름을 가져가면 안 된다.
- 문서와 실제 구현이 어긋나지 않게 변경 즉시 동기화해야 한다.
