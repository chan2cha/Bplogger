# Pulse Log 기획 정리

## 1. 기획 요약

Pulse Log는 날짜 단위 건강 기록 앱이다.
현재 제품 중심은 `빠른 입력`, `즉시 확인`, `가벼운 관리`다.

## 2. 현재 핵심 가치

- 빠른 저장: 앱 첫 진입 시 오늘 날짜를 기본 선택하고 바로 기록 입력
- 빠른 전환: 날짜를 바꾸면 즉시 해당 날짜 입력 대상으로 전환
- 빠른 확인: 월별 캘린더와 메모 마커로 상태 확인
- 선택적 관리: 더 깊은 수정/삭제/메모는 상세 화면에서 수행

## 3. 현재 사용자 시나리오

### 시나리오 A. 오늘 기록 저장

1. 사용자가 앱을 실행한다.
2. 앱은 오늘 날짜를 기본 선택한 상태로 캘린더 탭을 보여준다.
3. 사용자는 빠른 입력 카드에서 아침 혈압, 저녁 혈압, 체중을 입력한다.
4. 저장 직후 스낵바 피드백이 뜨고 캘린더 상태가 즉시 갱신된다.

### 시나리오 B. 다른 날짜 기록 수정

1. 사용자가 캘린더에서 날짜를 선택한다.
2. 메인 입력 대상 날짜가 즉시 바뀐다.
3. 입력 필드에는 해당 날짜 저장값이 반영된다.
4. 사용자는 같은 화면에서 바로 수정한다.

### 시나리오 C. 메모와 삭제 관리

1. 사용자가 선택 날짜의 세부 관리가 필요하다.
2. 상세 화면으로 진입한다.
3. 상세 화면에서 삭제, 메모, 측정 시간 확인을 수행한다.

## 4. 현재 화면 구조

- 상단 헤더
- 세그먼트 탭
  - 캘린더
  - 그래프
  - 설정
- 날짜별 상세 화면

## 5. 탭별 기획 포인트

### 5.1 캘린더 탭

- 프리미엄 톤의 월력 카드가 상단에 위치한다.
- 선택 날짜 요약과 메모 요약이 함께 보인다.
- 메모가 있는 날짜는 별표로 표시한다.
- 선택 날짜 아래에서 바로 빠른 입력을 수행한다.

### 5.2 그래프 탭

- 최근 7일 / 최근 30일 전환 제공
- 혈압과 체중을 같은 화면에서 확인
- 간단하고 빠른 추세 확인 중심

### 5.3 설정 탭

- 알림 시간과 재알림 정책 저장
- 빠른 입력 카드와 같은 시각 톤 유지

## 6. 현재 구현 완료 범위

- 메인 화면 빠른 입력 우선 구조
- 컴팩트 월력 UI
- 메모 별표 표시
- 선택 날짜 메모 요약
- 스낵바 피드백
- 바깥 영역 터치 시 키보드 내림
- 입력 화면과 설정 화면 톤 통일
- 화면 파일 분리 리팩터링

## 7. 다음 기획 우선순위

### Phase 1. 안정화

- 세그먼트 탭 동작 안정화 유지
- 상세 화면 입력 컴포넌트 톤 통일
- 시간 입력 UX 개선

### Phase 2. 기능 완성

- 실제 알림 스케줄링
- DB 마이그레이션 전략
- 런처 앱명 / 아이콘 정리

### Phase 3. 품질 강화

- UI 테스트
- ViewModel 테스트
- 접근성 개선
- 상태 복원 검증

## 8. 기획상 주의점

- 입력이 확인보다 늦게 인지되면 안 된다.
- 캘린더는 예쁜 배경이 아니라 상태 확인 도구여야 한다.
- 상세 화면이 다시 메인 입력 역할을 가져가면 안 된다.
- 문서와 실제 구현이 계속 어긋나지 않게 변경 즉시 동기화해야 한다.
